# زاد المسلم — V3

نسخة مطورة من مشروع زاد المسلم.

## أهم التحديثات
- مكتبة حديث متعددة الكتب مع بحث وصفحات.
- أذكار الصباح والمساء موسعة إلى 24 ذكرًا من فصل أذكار الصباح والمساء في حصن المسلم.
- 10 قراء في مركز التلاوات، مع إبراز ياسر الدوسري والمنشاوي.
- القرآن، البحث، الصلاة، القبلة، الأذكار، الأسماء الحسنى، رمضان والإعدادات.

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح http://localhost:3000

## ملاحظات المصادر
- القرآن والصوت: Al Quran Cloud / Islamic Network وموفر التلاوات المستخدم في المشروع.
- الحديث: i-muslim كمصدر API مفتوح للأحاديث العربية مع اسم الكتاب والمرجع.
- الأذكار: فصل أذكار الصباح والمساء من حصن المسلم، مع عرض المرجع داخل التطبيق.

راجع تراخيص المصادر وشروطها قبل أي استخدام تجاري أو نشر واسع.
